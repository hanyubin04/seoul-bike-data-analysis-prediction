# 🚲 Seoul Bike Data Analysis & Demand Prediction

서울시 공공자전거(따릉이) 이용 데이터와 기상 데이터를 분석하고,
Random Forest를 활용하여 따릉이 대여량을 예측한 머신러닝 프로젝트입니다.

## 📌 Project Overview

따릉이 대여량에 영향을 미치는 요인을 분석하고,
기상 정보와 날짜 정보를 활용하여 대여량을 예측하는 것을 목표로 진행했습니다.

서울시 공공자전거 대여 데이터와 기상 데이터를 수집한 후
데이터 전처리 및 병합을 수행하고,
기온·강수량·풍속·습도와 월·요일 등의 변수를 활용하여
따릉이 대여량과의 관계를 분석했습니다.

이후 Random Forest Regressor 모델을 학습하여
따릉이 대여량을 예측하고 모델의 성능을 평가했습니다.

## 🤖 Demand Prediction

전처리된 데이터를 기반으로 **Random Forest Regressor** 모델을 학습하여
따릉이 대여량을 예측했습니다.

- **Model**: Random Forest Regressor
- **Input (X)**: 평균기온, 강수량, 풍속, 습도, 월, 요일
- **Target (y)**: 따릉이 대여건수
- **Evaluation Metric**: R² Score
